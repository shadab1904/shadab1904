### Shift-Left CI/CD Security Workflow

```text
Developer → Git Push
         ↓
     Pull Request (mandatory review, branch policies)
         ↓
     ┌─────────────────── VALIDATE STAGE ───────────────────┐
     │  terraform fmt → terraform validate → tflint → tfsec  │
     │  Checkov → TruffleHog → SonarQube Quality Gate        │
     └───────────────────────────────────────────────────────┘
         ↓
     ┌─────────────────── COST STAGE ───────────────────────┐
     │  Infracost → Cost Delta Report → Manual Approval Gate │
     └───────────────────────────────────────────────────────┘
         ↓
     ┌─────────────────── BUILD STAGE ──────────────────────┐
     │  terraform plan → Plan Artifact Publish               │
     └───────────────────────────────────────────────────────┘
         ↓
     ┌─────────────────── DEPLOY STAGE ─────────────────────┐
     │  terraform apply → Smoke Tests → Drift Detection      │
     └───────────────────────────────────────────────────────┘
         ↓
     ┌─────────────────── ROLLBACK STAGE ───────────────────┐
     │  On Failure: Auto-Rollback → Notify → Incident Create │
     └───────────────────────────────────────────────────────┘
```

# 🔄 CI/CD Pipeline Architecture

**Azure DevOps** with YAML templates + **GitHub Actions** for open-source workflows.

```text
┌──────────────────────── PIPELINE TEMPLATE CHAIN ────────────────────────────┐
│                                                                               │
│  main.yml                                                                    │
│    ├── validate-test.yml   (fmt, validate, lint, security scan)              │
│    ├── cost.yml            (Infracost plan + delta report)                   │
│    ├── build.yml           (terraform plan → artifact publish)               │
│    ├── deploy-dev.yml      (apply → smoke test → drift check)                │
│    ├── deploy-uat.yml      (apply → integration test → sign-off gate)        │
│    ├── deploy-prod.yml     (apply → health check → manual approval)          │
│    └── rollback.yml        (triggered on failure → state revert)             │
│                                                                               │
│  Branching Strategy: Trunk-based                                             │
│  ├── main (protected, no-delete, required reviewers, code owners)            │
│  ├── feature/* (short-lived, auto-deleted after merge)                       │
│  └── hotfix/* (emergency patches, expedited review)                         │
└───────────────────────────────────────────────────────────────────────────────┘
```
